# Сохранённые стабильные версии

Здесь хранятся контрольные версии отдельных частей автоматизации, которые не входят в основной код напрямую.

- `reader-stable/MangaBuffAutomation.kt` — проверенная версия логики читалки.
- `ads-stable/MangaBuffAutomation.kt` — стабильная версия логики рекламы.

Основной проект находится в корне репозитория.
