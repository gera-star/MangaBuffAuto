# MangaBuffAuto — Multi-account / WebView fixes

Исправлено по логам переключения аккаунтов и статистики.

## Основные исправления

1. **Кристаллы/статистика аккаунта**
   - Каждый аккаунт получает собственный WebView Profile `mb_<accountId>`.
   - Сохранённые при добавлении аккаунта cookies импортируются в его профиль, если профиль пустой.
   - `CookieManager.getInstance()` больше не используется как источник cookies для именованных профилей.
   - Проверка авторизации на `/balance` больше не зависит от `window.isAuth`.
   - При ошибке/таймауте статистики значения не заменяются на `0`.
   - Успешно считанные значения сохраняются для отображения после перезапуска приложения.

2. **Переключение аккаунтов без перезапуска приложения**
   - WebView аккаунта не уничтожается при Stop; останавливается только загрузка.
   - `AndroidView` получил `key(webView)`, поэтому Compose действительно отсоединяет WebView предыдущего аккаунта и прикрепляет WebView нового.
   - Callback очистки активного WebView защищён от гонки при переключении аккаунтов.
   - Добавлен `runGeneration`, чтобы старый coroutine/job не мог после Stop перезаписать состояние нового запуска.
   - Один WebView/Profile остаётся закреплённым за одним accountId и может быть повторно использован.

3. **Белый экран при старте**
   - Оконный фон и Android 12+ splash background переведены на стабильный цвет приложения вместо белого системного preview.

4. **Reader по текущему логу**
   - Возвращён Golden baseline: `40s`, `300px` каждые `2s`.
   - Ранний `BOTTOM_DETECTED` больше не завершает главу раньше 40 секунд.
   - Автоклик `След. глава` после завершения главы удалён: следующий переход делает Kotlin state/loop, чтобы не было двойного открытия одной главы.
   - `SERVER_READ_MARK_CONFIRMED` больше не выдаётся только на основании локального завершения скролла.
   - `SERVER_READ_MARK_TIMEOUT` больше не считается успешным чтением.

5. **Дополнительно**
   - `WebViewClient` устанавливается до `loadUrl()` в balance/reader путях.
   - Убран старый жёсткий fallback комментария на конкретную главу/ID.

## Важная проверка после открытия проекта

Запустить `assembleDebug` локально в Android Studio.

В Logcat при старте аккаунта ожидаются примерно такие события:

`SESSION: PROFILE_COOKIES_IMPORTED profile=mb_<id> count=N`

`PROFILE: VERIFY expected=mb_<id> actual=mb_<id>`

`WEBVIEW: ATTACHED accountId=<id>`

`STAT: 💎 ...`

При Stop первого и Start второго аккаунта должны появиться `WEBVIEW: DETACHED` для первого и `WEBVIEW: ATTACHED` для второго без перезапуска приложения.
