# MangaBuffAutoBackground

Отдельное Android-приложение для фоновой автоматизации MangaBuff.

Это экспериментальная новая архитектура рядом с исходным MangaBuffAuto:
- automation/runtime принадлежит Foreground Service;
- Activity/Compose выступают только UI;
- состояние запуска сохраняется для START_STICKY recovery;
- WebView не уничтожается из Activity lifecycle;
- applicationId: com.example.myapplication.background

Исходное приложение в корне репозитория не изменяется.

## Нижнее меню и кнопки

Панель содержит только иконки. Порядок слева направо:

1. **Аккаунты** — список добавленных аккаунтов и управление ими.
2. **Задачи** — управление автоматическими задачами и их параметрами.
3. **Web (глобус)** — открывает WebView. Если доступно несколько WebView-аккаунтов, нажатие показывает список для выбора аккаунта.
4. **Поддержка (сердце)** — открывает информацию о добровольной поддержке проекта.
5. **Логи (список)** — просмотр, очистка и копирование журнала.
6. **Добавить аккаунт (человек с плюсом)** — открывает окно добавления аккаунта.
7. **Настройки (шестерёнка)** — настройки фоновой работы.

Когда WebView открыт, над значком **Web** появляется отдельная круглая кнопка со стрелкой возврата. Нажатие возвращает к интерфейсу приложения. В обычном режиме эта кнопка скрыта.

Верхняя панель приложения с надписью «MB+» удалена: содержимое начинается сразу под системной строкой Android с часами и индикаторами.

### Башня Разлома

В разделе **Задачи** настройки усилений «Башни Разлома» по умолчанию свёрнуты. Нажмите на заголовок карточки или стрелку справа, чтобы раскрыть параметры навыков; повторное нажатие сворачивает их.
