# MangaBuffAuto V10.0 — Reader Best

База: V9.9 Background Reader.

## Что изменено

- Подтверждённый селектор MangaBuff Helper для следующей главы: `a.button[rel="next"]` используется первым.
- Сохраняется резервный поиск следующей главы по реальному URL/номеру главы.
- 1x и 2x теперь используют одну шкалу скорости: 2x ровно в два раза быстрее 1x.
- Native background scroll работает только когда приложение действительно находится в фоне или экран выключен. В foreground native-scroll не добавляется к обычному скроллу, поэтому 1x не превращается в 2x.
- При переходе в background JS fallback-scroll останавливается, а native heartbeat берёт прокрутку на себя.
- При возврате в foreground обычная логика читалки восстанавливается.
- Отложенный переход на следующую главу теперь имеет отдельный timer и отменяется при Manual Stop.
- Существующая защита от старых runId/documentId сохранена.
- WakeLock сохраняется только на время активной ReadTask.
- CAPTCHA/Cloudflare/403 не обходятся.

## Конец манги

Если следующая глава не найдена и на странице есть реальный элемент «уведомить о выходе», существующая логика считает мангу законченной:

1. подтверждает конец;
2. пытается отметить мангу как прочитанную;
3. после успешного подтверждения возвращается в каталог с `?hide_read=1`;
4. задача не пытается генерировать несуществующий URL следующей главы.

## Проверка

- JavaScript ReadTask проверен через Node.js syntax check.
- Изменённые Kotlin-файлы проверены Kotlin compiler parser'ом; ошибок синтаксиса не обнаружено.
- Полный Gradle build в среде упаковки невозможен: Gradle Wrapper требует загрузку Gradle 9.6.0 с services.gradle.org, а сетевой DNS недоступен.
