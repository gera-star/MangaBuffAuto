## ⚙️ Возможности

- 📖 **Чтение глав** — последовательное чтение, проверка конца главы и подтверждение через MangaBuff history.
- ⚔️ **Бои** — автоматическое выполнение боевых циклов и получение наград.
- 🧠 **Квиз** — автоматическое прохождение заданий.
- 📺 **Реклама** — автоматический просмотр доступной рекламы.
- ⛏️ **Шахта** — добыча руды, улучшения и обмен.
- 🎟️ **Промокоды** — автоматическая обработка промокодов.
- 💬 **Комментарии** — случайные комментарии после заданного количества прочитанных глав.
- 👥 **Несколько аккаунтов** — отдельные профили WebView и последовательный запуск задач.
- 🔋 **Фоновая работа** — Foreground Service, WakeLock и защита автоматизации от остановки приложения.

## 🎛️ Интерфейс приложения

Актуальное расположение кнопок нижнего меню, открытие/закрытие Web и сворачивание настроек «Башни Разлома» описаны в [руководстве по кнопкам](MangaBuffAutoBackground/README.md#нижнее-меню-и-кнопки) для приложения `MangaBuffAutoBackground` в ветке `background-rebuild`.

### Кнопки в разделе «Аккаунты»

- **Аватар с инициалами** — открыть баланс аккаунта на MangaBuff в отдельном окне.
- **ONLINE / OFFLINE** — разрешить или приостановить автоматизацию для выбранного аккаунта.
- **🎲 Скип мангу** — отметить текущую мангу как прочитанную и вернуться в каталог, чтобы выбрать другую. Пропускается вся манга, а не только глава.
- **▶ Запуск / ⏹ Стоп** — запустить все выбранные задачи для аккаунта или остановить его текущую работу.
- **🔄 Обновить** — обновить баланс и статистику аккаунта с MangaBuff.
- **🗑 Удалить** — удалить аккаунт после подтверждения.
- **⌄ / ⌃ Развернуть / свернуть** — показать или скрыть переключатели задач этого аккаунта.

В раскрытой карточке аккаунта доступны переключатели **Бои**, **Башня Разлома**, **Реклама**, **Шахта**, **Чтение**, **Комментарии** и **Колоды**. Они включают или выключают соответствующую задачу только для этого аккаунта. Общие параметры запуска находятся во вкладке **Задачи**.

Подробное руководство по кнопкам: [README приложения](MangaBuffAutoBackground/README.md#кнопки-на-карточке-аккаунта).
