## 🔎 MangaBuffAuto — мангабафф бот и авто чтение MangaBuff

**MangaBuffAuto** — стороннее Android-приложение для автоматизации части повторяющихся действий при работе с MangaBuff.

Проект рассчитан на пользователей, которые ищут **манга бот**, **MangaBuff бот**, **бот для MangaBuff**, **авто чтение MangaBuff**, автоматическое чтение манги, автоматический скроллинг и работу MangaBuff в фоне на Android.

> **Важно:** MangaBuffAuto не является официальным приложением или официальным ботом MangaBuff.

---

## ✨ Что это?

Приложение использует встроенный **WebView**, Automation Engine и набор задач, которые могут выполняться последовательно и в фоновом режиме.

### Возможности

- 📖 автоматизация чтения и авто чтение MangaBuff;
- 🖱️ автоматический скроллинг;
- 🔄 восстановление состояния;
- 🌐 встроенный WebView;
- 👆 навигация жестами между страницами;
- ⏱️ фоновые задачи;
- 📢 работа с рекламными окнами;
- 💬 автоматические комментарии;
- 📊 статистика действий;
- 🧪 диагностический журнал;
- 🛡️ защита от конфликтов между задачами;
- 🧹 обслуживание WebView и контроль памяти.

> ⚠️ Сайт MangaBuff может изменяться. Отдельные функции могут потребовать обновления после изменений на стороне сайта.

## ⚙️ Что разрешить на телефоне для стабильной работы

Для обычного использования нужен доступ к интернету.

Для **длительного авто чтения, фоновой автоматизации и работы при заблокированном экране** рекомендуется:

- 🔋 **Батарея → Без ограничений / Не ограничивать** для MangaBuffAuto;
- 🚀 **Автозапуск → Разрешить**, если такой пункт есть в прошивке;
- 🌙 разрешить приложению работать **в фоне** и не переводить его в режим сна;
- 🔔 разрешить **уведомления**, если они используются системой для фонового сервиса;
- 🔋 отключить для MangaBuffAuto агрессивную оптимизацию батареи, если такая настройка присутствует;
- 📲 после изменения системных ограничений перезапустить приложение.

### Xiaomi / HyperOS

Названия пунктов могут отличаться в зависимости от версии HyperOS. В первую очередь проверьте настройки приложения MangaBuffAuto в разделах **Батарея**, **Автозапуск**, **Разрешения** и **Другие разрешения / Фоновая работа**, если такие пункты присутствуют.

**Приложению не нужны контакты, SMS, камера, микрофон или геолокация.**
