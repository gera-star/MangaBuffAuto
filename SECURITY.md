# 🔐 Security

Если вы обнаружили потенциальную проблему безопасности, не публикуйте чувствительные детали в открытом Issue.

Используйте приватный канал связи с разработчиком проекта.

Никогда не отправляйте:

- пароли;
- cookies;
- session/access tokens;
- приватные ключи;
- персональные данные.

Для обычных ошибок используйте GitHub Issues.
