# MangaBuff Auto — V10.5 Automation Final

Эта сборка продолжает V10.4 и добавляет автоматический планировщик, не меняя основной принцип безопасности: только один активный WebView-task за раз.

## Что добавлено

- `AutomationScheduler` живёт вместе с `AutomationRuntime` и Foreground Service.
- Автоматический режим включается вручную в окне «Профили».
- В автоматическом режиме для текущего WebView-профиля:
  - чат — примерно раз в 15 минут 30 секунд;
  - чтение — раз в час;
  - шахта — не чаще одного запуска в сутки;
  - реклама — не чаще одного запуска в сутки.
- Расписание хранится отдельно для каждого WebView-профиля.
- Задачи никогда не выполняются параллельно.
- CAPTCHA / блокировка / renderer crash останавливают автоматический запуск.
- Автоматического переключения аккаунтов нет. Профили остаются изолированными WebView-сессиями и переключаются вручную.
- Reader получил дополнительную проверку реального `div.reader__footer` перед переходом к следующей главе, сохранив старый fallback по `scrollHeight`.
- Реклама не закрывается раньше минимального 35-секундного ожидания после запуска объявления; закрывается только найденным DOM-элементом.
- `TaskManager` + `runId` + `docId` продолжают защищать от результатов старых JS-документов.

## Что намеренно НЕ добавлено

- CAPTCHA/Cloudflare bypass.
- fingerprint/User-Agent spoofing.
- IP/proxy rotation для обхода блокировки.
- автоматическое скрытое переключение аккаунтов.
- автоматические комментарии/спам.
- Quiz network interception: пока нет безопасной подтверждённой реализации для WebView.
- копирование Selenium anti-detection из MangaBuffAutoDaily.

## Multi-Profile

Используется AndroidX WebView Multi-Profile. Каждый профиль имеет отдельные cookies/WebStorage. Пароли приложение не хранит.

## Сборка

В Android Studio открыть корень проекта и выполнить Gradle Sync, затем `app` → Run.

Полная Gradle-сборка в среде подготовки архива не была выполнена только потому, что здесь Gradle Wrapper не смог скачать Gradle 9.6.0 из-за отсутствия DNS-доступа к services.gradle.org. Независимая Kotlin syntax-проверка новых scheduler/task файлов прошла.
