# 📱 Установка MangaBuffAuto

## 1. Скачать

Откройте **GitHub → Releases** и скачайте APK нужной версии.

Текущий публичный релиз:

**MangaBuffAuto v1.0.0**

## 2. Установить

1. Откройте APK.
2. Если Android запросит разрешение, разрешите установку из неизвестного источника для используемого приложения.
3. Завершите установку.
4. Запустите MangaBuffAuto.

## 3. Первый запуск

1. Откройте MangaBuff внутри приложения.
2. При необходимости выполните вход.
3. Настройте нужные функции автоматизации.
4. Перед длительной автоматизацией рекомендуется проверить работу на одной странице.

## 4. Настройки для длительной работы

Для обычного использования нужен интернет.

Для авто чтения, фоновой автоматизации и работы при заблокированном экране рекомендуется открыть настройки приложения MangaBuffAuto и проверить:

- **Батарея → Без ограничений / Не ограничивать**;
- **Автозапуск → Разрешить**, если такой пункт есть;
- разрешить работу приложения **в фоне**;
- разрешить **уведомления**, если система использует их для фонового сервиса;
- отключить агрессивную оптимизацию батареи для приложения, если такая настройка доступна.

### Xiaomi / HyperOS

Названия пунктов зависят от версии HyperOS. В первую очередь проверьте **Батарея**, **Автозапуск**, **Разрешения** и настройки фоновой активности приложения.

После изменения ограничений рекомендуется перезапустить MangaBuffAuto.

**Приложению не требуются контакты, SMS, камера, микрофон или геолокация.**

## 🔐 Важно

Пароли, cookies, session token и другие данные авторизации не нужно передавать разработчику.

MangaBuffAuto — независимый сторонний Android-проект и не является официальным приложением MangaBuff.
