# 🤝 Contributing

Спасибо за интерес к MangaBuffAuto.

## 🐛 Bug Report

Перед созданием Issue:

1. Проверьте [FAQ](docs/FAQ.md).
2. Проверьте [Troubleshooting](docs/TROUBLESHOOTING.md).
3. Укажите версию приложения.
4. Укажите модель устройства и версию Android.
5. Опишите точные шаги воспроизведения.

### 🔐 Не публикуйте

- пароли;
- cookies;
- session/access tokens;
- ключи;
- персональные данные.

## 🔧 Pull Request

Перед отправкой изменений:

- сохраняйте существующую архитектуру;
- не удаляйте рабочую функциональность без необходимости;
- проверяйте сборку;
- тестируйте WebView;
- отдельно проверяйте автоматизацию и навигационные жесты;
- описывайте назначение изменений.
